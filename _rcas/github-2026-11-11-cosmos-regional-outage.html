问题陈述

Problem
这些 GitHub 产品依赖的 Azure Cosmos DB 账户所在区域出现故障。GitHub 转述：Central US 网关的一次配置变更，在特定高负载流量模式下暴露潜伏竞态，网关崩溃并导致健康检查失败。Cosmos 回滚该变更后缓解。 官方事实
Impact
2026-11-11 20:05–21:02 UTC（11-12 04:05–05:02 Asia/Shanghai），约 57 分钟。状态页 impact=critical。Actions 启动延迟或失败，webhook 报错与投递延迟，Apps API 变慢，Copilot 可用性下降，Pages 构建延迟。20:18–20:55 UTC 的 Actions 几乎全部延迟或失败，留下约 340 万个部分创建的 runs。事故期间没有 Pages 部署完成。Central US 数据驻留戳上约 63% 的 webhook API 失败，27% 的投递未被记录。Copilot code review 完成量少 87%。用户数：报告未说明 官方事实
When
20:05 UTC 客户影响开始。状态页 20:48 UTC 才出现，距起点约 43 分钟，最初只写 Pages，不能写成已证实的 MTTD。21:02 UTC 服务健康恢复。21:21 UTC Actions 积压处理完。约 340 万 runs 在 RCA 发布时仍在取消。 官方事实
Where
这些服务使用的 Azure Cosmos DB 账户所在区域。供应商侧写的是 Central US 网关。webhook 数字写在 Central US data residency stamp。其他区域是否同等受损：报告未说明 官方事实
Frequency
一次约 57 分钟的区域依赖故障。服务健康在 21:02 UTC 恢复，Actions 积压到 21:21 UTC 处理完。部分创建的 runs 在依赖恢复之后仍然存在。 官方事实
