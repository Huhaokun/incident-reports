问题陈述

Problem
schema 迁移把 BsRequest 的 BsRequestAction 计数默认成 0，新代码却假定每条 BsRequest 至少有一个 action。回填完成前，watchlist 里带有这类 request 的用户打开任何页面都会崩溃。 官方事实
Impact
2026-11-03，build.opensuse.org。受影响用户访问每一个页面都遇到 500，官方写大约一小时。部署 10:25 UTC 开始，约 11:36 UTC 崩溃停止，11:45 UTC 纠正迁移全部完成。用户数、请求数、构建任务是否中断：报告未说明。不是 openSUSE 或 OBS 的全局停服。 官方事实
When
10:27 UTC 执行 schema 迁移。10:31 UTC 问题跟踪里首次出现应用异常，距 schema 迁移 4 分钟。10:32 UTC 启动数据迁移，10:46 UTC 因怀疑它造成退化而停止。11:20 UTC 定位，11:26 UTC 开始手动执行调整后的迁移，11:36 UTC 崩溃停止，11:45 UTC 关闭。书面复盘 11-13 发布，没有时刻。 官方事实
Where
OBS 参考服务器 build.opensuse.org 上、watchlist 里带有 request 的部分用户。崩溃在 request 与 watchlist 的组合上。代码行和受影响行数：报告未说明 官方事实
Frequency
官方复盘写的是这次部署。此前是否有过同样的默认 0 崩溃：报告未说明
