问题陈述

Problem
一阵高并发、大体积的读请求打到存储 Actions Checks 数据的数据库，服务陷入内存压力，停滞并拒绝请求。对受影响的数据库主机做了故障转移。 官方事实
Impact
2026-11-05 16:39–16:57 UTC（11-06 00:39–00:57 Asia/Shanghai），约 18 分钟。状态页 impact: minor。峰值约 3% 的 workflow 无法入队，约 0.21% 的进行中 runs 失败。主要冲击在入队。
When
16:39 UTC 影响开始。状态页 16:50 UTC 创建，约 11 分钟后。16:57 UTC 窗口结束。书面 RCA 在 11-13 更新到此页。内部检出渠道未写。
Where
存储 Actions Checks 数据的数据库服务。它是启动和更新 runs 的共享依赖。数据库类型和内存阈值未写。
Frequency
一次约 18 分钟的内存压力。内存容量已提高。大型查询并发限制未写完成态。这阵大读的来源未写，原文没有把它写成外部攻击。
