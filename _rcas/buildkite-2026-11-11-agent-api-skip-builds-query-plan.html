Problem
跳过构建的 SQL 按主键 ID 加当前状态更新。PostgreSQL 统计把 scheduled 行估成 1，规划器选了按状态的部分索引。该 pipeline 实际有数千条 scheduled 构建，查询从通常约 20ms 变成超过 1 秒。worker 并发拉起新的尝试，查询数量近似平方增长，15–20 分钟内几乎占满共享数据库。 官方事实
Impact
2026-11-11 18:40–20:02 UTC（11-12 02:40–04:02 Asia/Shanghai），约 1 小时 22 分。共享同一数据库集群的一部分客户，Agent 请求变慢或失败，agent 无法推进 jobs。受影响集群上完成的 jobs 比前一周低 50–75%；构建更慢，需要人工重试。入站 webhook 没有丢失。客户数、pipeline 数、集群规模：报告未说明 官方事实
