问题陈述

Problem
一次认证变更让 Web 请求绕过了本应延长会话寿命的活动更新和 cookie 续期。受影响会话在初始到期时间结束，即使用户持续使用也要重新登录。 官方事实
Impact
2026-11-05 18:02 UTC 至 2026-11-19 18:05 UTC（11-06 02:02 至 11-20 02:05 Asia/Shanghai），约 14 天。状态页 impact=minor。这是续期失效的窗口，不是持续全站登录失败。该时段的会话回来时仍可能被登出，重新登录即可。用户数、默认会话时长、是否波及 API / PAT / SSO 以外的浏览器会话：报告未说明 不是数据泄露或账户接管。 官方事实
When
11-05 18:02 UTC 是回溯的缺陷起点，不是发现时刻。官方认为修复在 11-19 05:23 UTC 生效。状态页 17:06 UTC 才出现，修复已经被认为已经发出。17:43 UTC 曾写成因不活动过期，随后的 RCA 纠正为活动没被记上。窗口结束写在 18:05 UTC。 官方事实
Where
浏览器里的 Web 会话续期路径。变更打在认证上。是代码发布还是配置推送：报告未说明 官方事实
Frequency
缺陷在生产中持续约 14 天。不是每一次请求都立刻掉线，而是会话走到初始到期时间才结束。 官方事实
