问题陈述

Problem
服务 Git HTTPS 的主机上堆积了过量连接，网络容量被打满，这些主机上的所有客户端都变慢或失败。负载均衡拦住一种客户端流量模式并重载后，多余连接被释放。 官方事实
Impact
2026-11-03 15:00–22:37 UTC（23:00 至 11-04 06:37 Asia/Shanghai），约 7 小时 37 分钟。状态页 impact 为 minor。约一半 Git HTTPS 流量的中位响应时间从不足 100 毫秒升到最高 5 秒。平均错误率 0.65%，峰值 1.29%。SSH 不受影响。拦截规则到 11-04 13:26 UTC 才撤销，期间某一未点名的第三方集成的部分用户无法走 HTTPS 做 Git 操作。
When
15:00 UTC 影响开始，22:37 UTC 主窗口结束。拦截规则持续到次日 13:26 UTC。书面 RCA 未写内部检出渠道，也没有给出状态页创建时刻。
Where
服务 GitHub.com Git HTTPS 的主机及其网络容量。SSH 是另一条路径。
Frequency
一次约 7.5 小时的 HTTPS 降级，外加次日才撤销的拦截副作用。更早的持续延迟告警、以及对已有连接立即生效的缓解，均未写完成态。
