问题陈述

Problem
2026-11-02，攻击者未授权进入 GitBook 系统。利用 SSO 登录流程中的缺陷创建冒充员工的登录会话，查询组织内一个配置不当的 GitHub App 的认证信息，进入内部代码仓库并最终获得 Cloudflare API key；再用该密钥取得生产密钥，通过一个服务账号获得完整基础设施访问。 官方事实
Impact
可用性：应用自 11-02 20:32 UTC 至 11-03 11:56 UTC 有意下线。官方称 about 16 hours；按这两个时刻相减是 15 小时 24 分。下线是遏制决定，不是攻击者把站点打挂。缓存的已发布站点在该窗口的一部分时间仍可访问。生产环境被访问约 2 小时 45 分（11-02 晚）加约 40 分（11-03 清晨）。攻击迹象指向一名客户，未发现其它客户内容被修改；官方仍把生产访问期间能够触及的客户数据全部按已暴露处理。可访问类别包括 GitBook API token、集成令牌与密钥、session signing secrets、向 GitBook Assistant 提出的问题、使用 authenticated access 的文档站点、客户已授权范围内的 GitHub 与 GitLab Git Sync 身份，以及 docs、spaces、change requests 等内容。明确未泄露：账单、密码、IP 地址。被访问的自身系统包括内部代码仓库、部分计算基础设施、边缘网络上已部署的代码与密钥；自身数据包括源代码、基础设施密钥、数据库凭据、集成令牌与 Git Sync 密钥。受影响客户总数、是否实际滥用、被针对的客户是谁：报告未说明。同页 11-03 16:21 CET 更新在正式复盘的「完全恢复」之后仍写少数服务可能降级，并多写了 MCP 重新认证；11-04 11:36 CET 更新写平台功能已恢复，但一次无关的 GitHub 故障仍影响 Git Sync。 官方事实
When
时间线为 UTC，Asia/Shanghai 为 UTC+8。11-02 12:27 UTC（20:27）目标客户处第一个账户被劫持，手段报告未说明，不能写成同一个 SSO 缺陷。16:32 UTC（11-03 00:32 Asia/Shanghai）获得员工会话并进入源代码。17:48 UTC（11-03 01:48）进入生产。18:10 UTC（11-03 02:10）未授权活动内部告警，调查开始。距进入生产 22 分钟、距员工会话 1 小时 38 分钟、距客户账户被劫持 5 小时 43 分钟，均为时刻相减，原文没有给出 MTTD。19:58 UTC（11-03 03:58）修复 SSO 缺陷。20:32 UTC（11-03 04:32）禁用被攻陷账号、切断攻击者、应用下线。17:48 到 20:32 相减是 2 小时 44 分，与官方 about 2:45 hours 接近；原文没有把这两个时刻定义成该窗口的起止。11-03 清晨约 40 分钟的第二段生产访问没有对应起止时刻。11-03 02:34 UTC（10:34）起用新密钥重部署并作废既有 API token；03:09 UTC（11:09）部署新的 Cloudflare Workers；06:00 UTC（14:00）开始准备带新凭据的版本；10:52 UTC（18:52）轮转 GitHub app keys；11:56 UTC（19:56）全部密钥轮转完并完全恢复；22:51 UTC（11-04 06:51）轮转 Git Sync 的 GitLab tokens。最早可见状态更新是 11-03 13:15 CET。2026 年 11 月欧盟已结束夏令时，CET = UTC+1，即 12:15 UTC、20:15 Asia/Shanghai，晚于下线约 15 小时 43 分。早期更新写 11-02 19:00 CET 获得部分基础设施凭据并立即发现；正式复盘的进入生产与告警分别是 18:48 CET 与 19:10 CET。以正式复盘为准。 官方事实
Where
升级链穿过 GitBook SSO、组织内的 GitHub App 集成、内部代码仓库、Cloudflare API key、生产密钥与服务账号。客户侧影响面是 GitBook 中存储的客户数据，以及客户已经授权给 GitBook 的 GitHub、GitLab 仓库范围。区域或云账号清单：报告未说明 官方事实
Frequency
这是一次已公开的入侵与有意停机。SSO 缺陷何时引入、此前是否被利用：报告未说明。官方称这不是对过时软件的广撒网扫描，而是针对一名客户，进入后的速度与精度指向 largely automation and AI。文中 2025 年末 Anthropic 报告里 AI 承担 80–90% 战术工作，是行业背景，不是本次工具的取证结论。 官方事实
