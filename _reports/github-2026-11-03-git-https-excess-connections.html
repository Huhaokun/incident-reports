元信息

  • 公司：GitHub
  • 标题：Incident with Git Operations
  • 书面 RCA 首句：On November 3, 2026, between 15:00 UTC and 22:37 UTC, Git operations over HTTPS on GitHub.com were degraded.
  • 事故日期：2026-11-03 15:00–22:37 UTC（23:00 Asia/Shanghai 至 11-04 06:37），约 7 小时 37 分钟。用于止血的负载均衡拦截规则到 11-04 13:26 UTC（21:26 Asia/Shanghai）才撤销，期间部分第三方集成的 HTTPS Git 操作仍受影响。
  • 原文：https://www.githubstatus.com/incidents/13b6lyl8d7bz
  • 类别：事故复盘
  • 严重度/时长：状态页 impact 在接口中为 minor（以页面为准）。约一半的 Git HTTPS 流量，中位响应时间从不足 100 毫秒升到最高 5 秒；该服务请求平均错误率 0.65%，峰值 1.29%。SSH 上的 Git 操作不受影响。
  • 原文完整度：中 / 紧凑。写清了 HTTPS 主机上多余连接堆积、打满网络容量，以及用负载均衡拦住某种客户端模式并重载来释放连接。未说明连接因何堆积，也未命名被拦的第三方集成。
  • 根因类别：容量/资源耗尽。导火索类型：无法判断。
  • 依据：直接原因是 “a buildup of excess connections on the hosts that serve Git HTTPS traffic, which saturated their network capacity”。原文没有说明堆积从何而来，只在止血时提到拦住一种客户端流量模式，故导火索不硬猜。
  • 归类由本站根据分析归纳，非原报告表述。

背景知识

  • Git HTTPS 与 SSH：两套不同的服务路径。这次只有 HTTPS 主机的网络容量被打满，SSH 不受影响。
  • 负载均衡器拦截：在入口丢掉或拒绝匹配某种模式的连接。这次靠它释放了多余连接，但规则覆盖面比预期更宽，伤及另一第三方集成，直到次日才撤销。

1. 影响

GitHub.com 上 HTTPS 的 clone、fetch、push 变慢，部分失败。约一半 Git HTTPS 流量的中位响应时间从不足 100 毫秒升到最高 5 秒。平均错误率 0.65%，峰值 1.29%。SSH 不受影响。止血用的拦截规则在撤销前，还让某一第三方集成的部分用户无法走 HTTPS 做 Git 操作，直到 11-04 13:26 UTC 撤销。该集成名称未写。

2. 导火索

官方未写连接因何开始堆积。

3. 根因

直接原因

服务 Git HTTPS 的主机上堆积了过量连接，网络容量被打满，这些主机上的所有客户端都变慢或失败。

促成因素

负载均衡侧的缓解不能立刻作用在已有连接上（事后才写要让缓解对现有连接立即生效）。一种客户端流量模式与堆积有关，但原文只在止血步骤中提到它，没有把它写成已证实的起始原因。

防护为何没挡住

当时没有足够早的 Git HTTPS 持续延迟告警；也没有能立即清理已有过量连接的负载均衡手段。

4. 怎么发现

书面 RCA 未写内部检出渠道。

5. 止血与修复

临时：在负载均衡器上拦住一种客户端流量模式并重载，多余连接被释放。该拦截也导致某一第三方集成的部分用户直到次日 13:26 UTC 才能恢复 HTTPS Git 操作。

永久（官方）：正在做 Git HTTPS 持续延迟的更早告警，并让负载均衡缓解能立即作用于已有连接。未写完成态。

6. 影响为何扩大

连接打满的是主机网络容量，因此这些主机上的所有 HTTPS 客户端都受影响，不只是引发堆积的那一类流量。止血规则本身又误伤了另一组第三方集成用户，影响持续到次日。SSH 路径分开，所以没有被波及。

7. 既有防护与 SOP

防护或 SOP是否存在本次表现
SSH 与 HTTPS 分离存在SSH 未受影响
负载均衡拦截特定客户端模式存在（事中用了）释放了多余连接，但也误伤第三方集成
对已有连接立即生效的缓解事后改进当时不能立刻清理已有连接
Git HTTPS 持续延迟告警事后改进事发时是否已有未写

8. 后续改进措施

  • Detect：更早告警 Git HTTPS 持续延迟（进行中）。
  • Mitigate：让负载均衡缓解对已有连接立即生效（进行中）。

9. 教训

  • 做得好：SSH 路径隔离，没有被 HTTPS 主机打满所牵连。
  • 做得差：用宽拦截规则止血会延长另一组用户的影响；缓解若不能作用在已有连接上，堆积会拖得更久。

10. 时间线摘要

  • 15:00 UTC（23:00）影响开始。
  • 22:37 UTC（06:37，11-04）主窗口结束。
  • 11-04 13:26 UTC（21:26）撤销拦截规则，第三方集成恢复 HTTPS。
